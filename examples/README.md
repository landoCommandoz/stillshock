# Examples

Every clip in this folder started as one photo and one tap in Stillshock.
`manifest.json` drives the Gallery tab in the app:

```json
{ "items": [ { "file": "disintegrate-portrait.mp4", "poster": "disintegrate-portrait.jpg", "effect": "Disintegrate", "note": "Sample portrait, vertical" } ] }
```

Outputs are generated with LTX-2.5 (open weights) on Comfy Cloud. Sample input photos come from picsum.photos (Unsplash license).
