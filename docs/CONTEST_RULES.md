# Contest rules as read on October 23, 2026

Source: https://comfy.org/open-source-higgsfield/ (all collapsed sections opened with Playwright).
The live page wins over these notes.

## Prizes
- Best Overall: $10,000, every entry is considered.
- Most Innovative: RTX 5090. "Demo video must explain why the submission is innovative."
- Most Viral: RTX 5090. "Delightful to use and made to be shared."
- Open Weights Only: RTX 5090. "No partner nodes or closed-source APIs, open-weights models only."
- 10 runner-ups: $250 in Comfy credits.
- VFX Workflow Built with LTX: $2,000 cash. "LTX must be the core video model in the workflow."
- Built with FLUX: FLUX API credits. Built with MiniMax H3: $1,000 in API credits.
- Each entry is eligible for one main category and one model-provider bonus.

## App requirements (exact wording)
- Your work must be built with ComfyUI. Run it however you like: entirely local, Comfy Cloud, the Developer Platform, Comfy Router, the Comfy SDK, or any mix of them.
- Your repo must include an open-source license and enough setup detail that someone else can run it on their own machine.
- Any other tools, models, or techniques you want to combine with it are fair game and must be explained in your demo video.
- All submissions must be lawful, SFW, and must not contain unlicensed IP or likenesses.
- By submitting, you agree to allow ComfyUI, Runpod, LTX, Black Forest Labs, and MiniMax to feature your work with credit across our channels.
- One submission per person.

## Prepare your submission
- GitHub repo: app code, workflow files, an open-source license, instructions to run it locally.
- Demo video: two minutes max.
- A link to try it: optional, strongly encouraged.
- Social post: link to your demo video on Reddit, X, IG, LI, YT, or TikTok tagging #OpenSourceHiggsfield.

## Q and A
- "We're judging the work, not your video editing or quality. The best demo shows your work in action with an explanation of how it was built."
- Build Nights are separate from the online competition.
- You may use partner models; only Open Weights Only requires open weights.

## Timeline
- Submissions close October 30, 9am PT. Winners announced November 6.
