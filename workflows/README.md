# Workflows

One API-format ComfyUI workflow per spell, generated by `scripts/export_workflows.py`
from `app/graph.py` and `app/spells.json`. The app submits the same graph with your
clip, size, seed and prompt filled in. `index.json` lists the model files each one needs.

All nodes are ComfyUI core: LoadVideo, GetVideoComponents, CheckpointLoaderSimple,
LTXAVTextEncoderLoader, LTXVAudioVAELoader, LoraLoaderModelOnly, GetICLoRAParameters,
CLIPTextEncode, LTXVConditioning, EmptyLTXVLatentVideo, LTXVEmptyLatentAudio,
ImageScale, LTXVAddGuide, LTXVConcatAVLatent, RandomNoise, KSamplerSelect,
ManualSigmas, CFGGuider, SamplerCustomAdvanced, LTXVSeparateAVLatent, LTXVCropGuides,
VAEDecodeTiled, LTXVAudioVAEDecode, CreateVideo, SaveVideo.

To run one by hand in ComfyUI: enable Dev mode, load the JSON, put your clip in
`input/` as `input.mp4` (24 fps, sized to the width and height in node 12), and queue.

The Lightricks repos are gated: log in to Hugging Face and accept the LTX-2 Community
License before downloading or importing into Comfy Cloud. The three template-library
LoRAs download automatically when you open those templates in ComfyUI.

Sampling follows the Lightricks distilled recipe: 8 fixed sigmas, euler_ancestral,
CFG 1, reference guide strength 1.0, downscale factor read from the LoRA metadata.
